# Antigravity Voyager LaTeX 公式美化与一键复制增强插件

专为 **Antigravity 2.x (macOS)** 定制的轻量级公式交互增强模块。复刻并增强 Gemini 网页端扩展 **Voyager** 的核心交互体验。

---

## 🌟 核心功能

1. **公式卡片化美化**：
   - 块级公式（`$$ ... $$` 或 `\[ ... \]`）：渲染为带微透明底色、圆角边框的代码块卡片，鼠标悬停右上角浮现 `📋 点击复制 LaTeX` 角标。
   - 行内公式（`$ ... $` 或 `\( ... \)`）：渲染为精致胶囊标签，鼠标悬停显示 LaTeX 源码预览。
2. **一键提取 LaTeX 源码**：
   - **单击公式**：直接把纯 LaTeX 源码复制到剪贴板，右下角弹出绿色轻量 Toast 提示。
   - **按住 Option (Alt) 单击公式**：自动携带 `$$...$$` 或 `$...$` 定界符复制。
   - **框选文字 Cmd+C 智能拦截**：鼠标拖拽选中整段包含公式的回答按 `Cmd + C` 时，自动将公式节点无缝还原为 Markdown 源码，解决原生 KaTeX 复制产生的乱码与文字重影。
3. **零网络依赖与纯离线**：
   - 完全依赖客户端本地 DOM 与 KaTeX 解析，绝不发起任何外部网络请求。
4. **与原有中文汉化 100% 安全共存**：
   - 独立注释标记注入 `dist/preload.js`，绝不修改任何汉化字典或汉化引擎核心代码。
   - 独立冷备 `app.asar.before-voyager`，绝不覆盖官方原版备份 `app.asar.bak`。

## 🚀 使用方法

### 1. 一键安装
1. 完全退出 Antigravity 应用程序（Cmd + Q）。
2. 双击运行 `双击安装公式增强.command`。
3. 按提示输入开机密码以授予修改权限（若已具备权限则无感跳过）。
4. 运行完成后重新启动 Antigravity，在 AI 聊天对话框中即可畅享公式一键复制！

### 2. 一键卸载还原
1. 完全退出 Antigravity 应用程序。
2. 双击运行 `双击卸载还原.command`。
3. 应用将无痕恢复至安装公式插件前的汉化状态。

## 🛡️ 安全与风险防范机制

1. **沙箱与风控安全**：
   - 本插件仅操作 Electron 前端渲染层的 DOM 样式与鼠标/剪贴板事件。
   - 绝不触碰任何网络请求（Fetch/XHR/RPC）、绝不触碰 Token/鉴权头、绝不干预任何大模型传输内容，不存在任何账号风控或封禁风险。
2. **防御性编程**：
   - 前端逻辑采用全方位 `try...catch` 包裹，遇到任何非标准 DOM 节点均静默跳过，绝不抛出任何未捕获异常。
3. **macOS Gatekeeper 签名防护**：
   - 每次重新打包 `app.asar` 后，引擎均自动调用 macOS 原生 `codesign --force --deep --sign -` 进行本地 Ad-hoc 签名，并清除 `xattr` 隔离属性，杜绝系统“应用已损坏”拦截。
